# AutoEat / Alimentação Automática

Client-side Pulsar plugin for **Space Engineers** that consumes compatible food from the engineer's personal inventory automatically.

Plugin cliente para Pulsar no **Space Engineers** que consome automaticamente alimentos compatíveis do inventário pessoal do engenheiro.

## Features / Recursos

- Enable or disable automatic eating from the player Terminal control panel.
- Set the hunger percentage at which the character eats.
- Set the hunger percentage for a prominent no-food warning.
- Configure the priority order for detected food items.
- Portuguese UI for Portuguese game languages; English for all other languages.
- `Ctrl + Alt + U` quickly toggles AutoEat.

---

- Ative ou desative a alimentação automática pelo painel de controle do Terminal do personagem.
- Defina a porcentagem de fome em que o personagem come.
- Defina a porcentagem de fome para o aviso chamativo de falta de comida.
- Configure a ordem de prioridade dos alimentos detectados.
- Interface em português quando o jogo está em português; em inglês nos demais idiomas.
- `Ctrl + Alt + U` alterna rapidamente o AutoEat.
